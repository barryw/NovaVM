\section{Common Shape}

Every game chapter should follow the same shape:

\begin{enumerate}
\item What the player sees.
\item What Nova hardware the program uses.
\item The listing.
\item How the listing works.
\item Experiments to try.
\end{enumerate}

That makes the book friendly for readers and maintainable for us.
