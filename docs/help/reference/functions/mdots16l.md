---
title: "MDOTS16L"
type: function
category: Math
keywords: [mdots16l, math, coprocessor, vector, dot]
syntax: "MDOTS16L(ax,ay,bx,by)"
see_also: [mdots16h, mdotfx, mlen2, mcrossl]
---

Return the unsigned low word of the signed 16-bit vector dot product.

The full operation is `ax*bx + ay*by`. Use `MDOTS16H` for the signed high word.
