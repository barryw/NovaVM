---
title: "MCROSSL"
type: function
category: Math
keywords: [mcrossl, math, coprocessor, vector, cross]
syntax: "MCROSSL(ax,ay,bx,by)"
see_also: [mcrossh, mdots16l, mdotfx, mlen2]
---

Return the unsigned low word of the signed 16-bit 2D cross product.

The full operation is `ax*by - ay*bx`. Use `MCROSSH` for the signed high word.
