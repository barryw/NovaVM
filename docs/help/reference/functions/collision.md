category: Sprites

see_also: [graphics-and-display]

Legacy sprite-to-sprite collision helper. For all 16 sprites, prefer `SPRCOLL`,
which returns the full 16-bit latched collision mask and clears it.

See the [Graphics And Display](/docs/help/guides/graphics-and-display.md) guide for more details.
