title: "MMUL16H"
type: function
category: Math
keywords: [mmul16h, math, coprocessor, multiply]
syntax: "MMUL16H(a,b)"
see_also: [mmul16l, mmulfx, mdots16h, mcrossh]
---

Return the signed high word of a signed 16-bit by signed 16-bit multiply.

Use `MMUL16L(a,b)` for the unsigned low word of the same 32-bit product.
