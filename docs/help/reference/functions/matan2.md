---
title: "MATAN2"
type: function
category: Math
keywords: [matan2, math, coprocessor, angle]
syntax: "MATAN2(dy,dx)"
see_also: [msin, mcos, mdist, mdiv]
---

Return an 8-bit angle for the signed vector `dx`,`dy`.

The result uses 0..255 for one full turn: 0 points right, 64 points up, 128 points left, and 192 points down.
