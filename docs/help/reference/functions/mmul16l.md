title: "MMUL16L"
type: function
category: Math
keywords: [mmul16l, math, coprocessor, multiply]
syntax: "MMUL16L(a,b)"
see_also: [mmul16h, mmulfx, mdots16l, mcrossl]
---

Return the unsigned low word of a signed 16-bit by signed 16-bit multiply.

Use `MMUL16H(a,b)` for the signed high word of the same 32-bit product.
