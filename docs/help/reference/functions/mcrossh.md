---
title: "MCROSSH"
type: function
category: Math
keywords: [mcrossh, math, coprocessor, vector, cross]
syntax: "MCROSSH(ax,ay,bx,by)"
see_also: [mcrossl, mdots16h, mdotfx, mlen2]
---

Return the signed high word of the signed 16-bit 2D cross product.

The full operation is `ax*by - ay*bx`. Use `MCROSSL` for the unsigned low word.
