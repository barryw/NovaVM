---
title: "MSIN"
type: function
category: Math
keywords: [msin, math, coprocessor, sine]
syntax: "MSIN(angle)"
see_also: [mcos, mdist, mmulfx, mrnd]
---

Return sine from the math coprocessor for an 8-bit angle, where 0..255 is one full turn.

The result is signed 1.7 fixed point in the range -128..127.
