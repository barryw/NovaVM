---
title: "MDOTS16H"
type: function
category: Math
keywords: [mdots16h, math, coprocessor, vector, dot]
syntax: "MDOTS16H(ax,ay,bx,by)"
see_also: [mdots16l, mdotfx, mlen2, mcrossh]
---

Return the signed high word of the signed 16-bit vector dot product.

The full operation is `ax*bx + ay*by`. Use `MDOTS16L` for the unsigned low word.
